# ownHub 🗂️

Hub personal de gestión de proyectos y tareas, accesible desde cualquier dispositivo.

Desarrollado desde cero como proyecto de aprendizaje de programación web.

---

## ¿Qué es esto?

Una aplicación web personal para organizar proyectos, tareas y pendientes usando una combinación de tres metodologías:

- **GTD** (Getting Things Done) — captura todo, confía en el sistema
- **Kanban** — visualiza el flujo: pendiente → en progreso → hecho
- **Matriz Eisenhower** — prioriza por urgencia e importancia
